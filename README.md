# Optimización de Proceso: Lanzamiento de Proyectil
**Objetivo:** Reducir la variabilidad del alcance a un objetivo de 130cm ± 10cm mediante el control estadístico de procesos (SPC).

## 📈 Metodología de Mejora Continua (Sesiones distintas)
Este proyecto sigue una estructura de sesiones diarias donde se filtran variables para alcanzar el estado de "Proceso en Control".

### Sesión 1: Selección de Equipo y Diagnóstico
* **Análisis de Estaciones:** Comparativa entre Estación 1 (Acero) y Estación 2 (Goma).
* **Herramientas:** Histogramas de densidad, Gráficos X-bar/R y Diagrama de Ishikawa.
* **Resultado:** Selección de la Estación 1 por su capacidad de estabilización superior.
